Trim

Accepted
-20.0 to 20.0 trim units. MSFS trim is normalised to 0 - 17, the X-Plane B738 dataref is the raw stabiliser value, calibration parks the needles at 5.0
Drives

Mock simulator values

Push values into the unit without running the simulator. The body is posted to /api/sim and goes through the same parser and the same driver callbacks as a UDP packet on port 49152, so the motors react exactly as they would to the real thing. Fields left empty keep their current value.

These move real levers. Throttles only follow when auto throttle is on, the speed brake only when its motor is enabled in Settings, trim always turns the needles. 
{}

Same endpoint from the command line, and a raw simulator payload is accepted too:

curl -X POST http://mtu.local/api/sim -H 'Content-Type: application/json' \
  -d '{"throttle1": 0.5, "autoThrottle": true, "parkingBrake": false}'

curl -X POST http://mtu.local/api/sim -H 'Content-Type: application/json' \
  -d '{"sim/flightmodel/engine/ENGN_thro": [0.5, 0.5], "laminar/B738/flt_ctrls/speedbrake_lever": 1.0}'
