Buttons

A box lights up when the switch is on. Listed in the order the switches reach the simulator as joystick buttons - bit N is HID button N+1. Reverse 1/2 (buttons 17/18) and trim up/down (19/20) are derived from the axes, not from a switch. Bit number is shown so a box can be matched to a physical switch.
